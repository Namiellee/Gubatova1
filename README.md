## 📋 Описание проекта

Разработана виртуальная система контроля условий хранения на складе зерна на базе Arduino Uno. Система опрашивает три датчика каждые 2 секунды, фиксирует превышение порога влажности (>70%) и автоматически загружает данные в базу SQLite через Node-RED для анализа и контроля неисправностей.

### Входные данные варианта
| Параметр | Значение |
| :--- | :--- |
| **Сценарий** | Склад зерна |
| **Датчик 1 (s1)** | NTC (температура, 0–50 °C), A0 |
| **Датчик 2 (s2)** | DHT22 (влажность воздуха), D4 |
| **Датчик 3 (s3)** | PIR HC-SR501 (движение), D2 |
| **Исполнительное устройство** | Зуммер BZ1, D7 |
| **Светодиод-индикатор** | Красный HL1, 20 мА, D8 |
| **Период опроса T** | 2 с |
| **Порог события** | Влажность s2 > 70 % |

Порядок запуска
1. Подготовка рабочего места
Распакуйте архив tools.zip в папку %USERPROFILE%\tools.
Убедитесь, что в папке tools находятся подпапки: git, node, sqlite, nodered.
Дважды кликните по файлу env.bat — откроется командная строка с настроенным окружением.
2. Запуск Node-RED
В открывшейся командной строке выполните:
bat
start-nodered.bat
Дождитесь сообщения «Server now running at http://localhost:1880» и откройте этот адрес в браузере.
3. Импорт потока
В интерфейсе Node-RED нажмите меню ≡ → Import.
Выберите файл nodered/flow.json и нажмите Import.
Нажмите кнопку Deploy в правом верхнем углу.
4. Запуск симуляции
Откройте проект в Wokwi.
Нажмите кнопку Play (F5).
Скопируйте вывод Serial Monitor и сохраните его в файл data/log.txt.
После сохранения файла поток автоматически загрузит данные в базу.
5. Проверка результатов
В командной строке (из п.1) выполните:
bash
sqlite3 db/variant.db ".read db/queries.sql"
🧪 Тестирование
Штатный сценарий
Журнал data/log.txt содержит 13 циклов измерений. При начальной влажности 91,5% формируется событие THRESHOLD, при снижении до 57,5% — NORMAL. Исполнительные устройства (зуммер, светодиод) управляются корректно.
Неисправность датчика
Файл data/log_fault.txt содержит строку с недопустимым значением влажности (120%). После загрузки в таблице events появляется запись типа FAULT с сообщением «датчик s2 вне диапазона». Данные исправных датчиков сохраняются без потерь.
