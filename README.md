Система предназначена для контроля температуры, влажности и движения на складе зерна.  
При влажности выше 70 % включаются зуммер и красный светодиод.
Ссылка на Wokwi: https://wokwi.com/projects/479211487579955201
Состав проекта
firmware-прошивка Arduino
sim-модель Wokwi
db-база данных и SQL-скрипты
nodered-поток Node-RED
data-журналы данных
docs-схемы, скриншоты и документация
Порядок запуска
1. Открыть проект Wokwi
2. Запустить симуляцию
3. Скопировать Serial Monitor в data/log.txt
4. Запустить start-nodered.bat
5. Открыть http://localhost:1880
6. Нажать Deploy
7. Проверить данные запросами из db/queries.sql
